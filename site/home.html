How it works

  1. Run the truck. Key on, start the engine, set a road speed and load. Gauges, lamps and network traffic all respond.
  2. Break something. An instructor (or the simulator) injects a fault: a shorted sensor, an open CAN wire, an air leak, a stuck governor.
  3. Diagnose it. Read codes and live data on the scan tool, probe circuits with the multimeter, run the air brake check with a stopwatch.
  4. Learn from the path. Every action is logged and replayable, so a student can see what they tested, in what order, and what a faster path would have been.

Questions

Do I need to install anything?

No. It runs in any modern browser, including school Chromebooks. A phone works too, though a tablet or laptop gives you room for the diagrams.

Is it a specific make of truck?

It is a generic heavy truck with a common engine, J1939 network and dual-circuit air brakes. Codes and specs follow the J1939 standard and typical heavy truck values rather than one brand's software.

Who is it for?

Diesel and truck technology students, apprentices, career changers and working techs who want more practice with electrical, network and air brake diagnosis.

Does it replace shop time?

No. It lets students arrive in the shop already knowing what a good reading looks like and how to work a fault, so shop time goes further.
